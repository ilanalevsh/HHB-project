# HHB Project

## Projekta apraksts

HHB ir digitālas platformas prototips, kas paredzēts ērtai lietotāju un datu pārvaldībai modernā un lietotājam draudzīgā vidē.

## Projekta mērķis

Izveidot mūsdienīgu platformu ar:
- autorizācijas sistēmu;
- datu bāzi;
- lietotāja profilu;
- ērtu dizainu.

## Izmantotās tehnoloģijas

- Figma
- HTML
- CSS
- JavaScript
- Python Flask
- SQLite

## Projekta struktūra

- frontend/ – lietotāja interfeiss
- backend/ – servera daļa
- database/ – datu bāzes faili
- docs/ – dokumentācija
- design/ – dizaina materiāli
